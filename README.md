# Aprendizado_de_maquina_Tiamat
Este repositório contém o projeto final da disciplina de Aprendizado de Máquina (Criatura Lendária: Tiamat), dedicado à predição e análise de respostas biológicas de moléculas a partir de descritores moleculares, aplicando validação cruzada estratificada, redução de dimensionalidade por PCA e otimização de hiperparâmetros com Optuna.
